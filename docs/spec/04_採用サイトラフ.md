## 2. デザインの方針

- **色**: 白〜ベージュを地に、緑をアクセントに。介護・福祉の法人サイトの共通言語で、「落ち着いて働ける」印象と合う。青は主色にしない（病院・求人媒体と同じ見え方になるため）
- **文字**: 読みやすい標準的なゴシック体。数字の強調に欧文書体
- **写真**: ファーストビューに写真を1枚。中身は素材を見て決める（トラベルヘルパーの活動写真は候補の一つ）
- **動き**: シンプルに。スクロールで要素がふわっと現れる、トップの写真がゆっくり切り替わる、の2〜3種類まで
- **費用**: 使う部品・書体はすべて無料

## 3. ページの構成

スマホで上から下へ読む1本道です。ゴールは説明会予約。ボタンは§1・§4の各カード・§6に置き、すべて説明会予約へ向けます。

**なぜ「応募」ではなく「説明会予約」をゴールにするか**

- 求人ページは2,000閲覧に対し応募1件。「応募」は求職者にとって段差が高い
- 一方、会社説明会には26名が参加。説明会が入口として機能している
- すぐの応募を希望する方は、フォーム内の選択肢で面接に直結させる

### §1 ファーストビュー

- キャッチコピー（2つの向きを用意。レビューで選ぶ）
  - A案「落ち着いて、長く働ける訪問介護へ」—— **働く環境**を前に出す。お打ち合わせで伺った「ウェルビーイング・落ち着いて働ける」の方針に沿う。「ここなら続けられそう」と感じてもらう向き
  - B案「その人らしい毎日を、支える仕事。」—— **仕事の価値**を前に出す。「先が見えない」という退職の本音に、仕事の意味で答える向き。県内の参考事例（わくわくの森）も「誰にでもできる仕事ではない」と理念で語っている
  - どちらの言葉で理念を語りたいかを決めていただく。文言そのものは仮
- 写真 1枚（素材は8月24日に受領予定）
- ボタン「説明会に参加する」
- 添え書き: ヘルパー・ケアマネ採用強化中／沖縄・那覇

### §2 数字・条件

- 職種別の給与・時給（例: 訪問介護員 時給 ¥X,XXX〜）
- 現サイトの時給表記の誤りは、ここで正しい数字に置き換える
- 裏づけられる数字だけを出す

### §3 働く環境

- 「従業員が働きやすい環境が、利用者の体験を良くする」を1〜2文で
- 派手なスローガンにしない

### §4 職種紹介（3カード）

- ヘルパー: 仕事内容とトラベルヘルパー同行の特色
- ケアマネジャー: 仕事内容。リモート勤務の実績あり
- 相談員: 仕事内容
- 各カードから予約へリンク

### §5 職員の声

- 資格・勤続年数・1日の流れを見せる枠
- 公開時は準備中表示、または1人分のみ。Instagramの連載で埋めていく
- 「続きはInstagramで」のリンクをここに置く（雰囲気をもっと見たい人の受け皿）

### §6 説明会予約（メインのボタン）

- 「見学だけでも歓迎」「まずは話を聞くだけもOK」の一文
- Googleフォームへのボタン
- フォームで「希望する次のステップ」を選べる: 説明会／見学／すぐに面接
- 実績の提示: 会社説明会に26名参加
- 履歴書などの個人情報はサイトでは受けない。正式な応募は説明会・面接のあと、または従来どおりIndeed・ハローワークで受ける（サイトからそちらへ誘導はしない）

### §7 会社概要

- 有限会社 沖縄介護センター／代表 又吉剛
- 沖縄県那覇市松川531-1・地図
- 事業内容: 看護師派遣・訪問介護・居宅介護支援・障がい者支援・介護タクシー・トラベルヘルパー（旅行付き添い）

### §8 フッター

- 会社名・所在地
- ご利用者・ご家族の方は現サイトへ
- Indeed等の求人媒体へのリンクは置かない。ゴールを説明会予約に絞るため（すぐ応募したい方は§6のフォームで「すぐに面接を希望する」を選べる）
