# 81webの採用サイト研究とヒーロー再検討

確認日：2026-09-06。ユーザーから初稿に対して「微妙」とのレビューを受け、81web掲載事例から構成を学び直すための記録。新しいデザイン方針は議論用で、実装の確定仕様ではありません。

## 議論後の決定

ユーザーの目的は、会社の雰囲気が伝わりやすくなること。スクロール先でも写真を見せられるため、ヒーローの複数枚にはこだわらない方針となり、「当初の構成に戻して」との指定を受けた。

ヒーローは当初の「左にコピー、右に大きな角丸写真1枚」へ復元。会社の雰囲気はページ全体の写真で伝える。撮影メモはヒーロー専用の3枚構成から、仕事・同僚との関係・職員の人柄を伝える場面別の構成へ更新する。以下の比較・3案は、その決定に至る検討記録として残す。

## 確認した範囲

- [81web 採用サイト一覧](https://81-web.com/type/recruitment-site/)をブラウザーで確認。Desktop切り替え時264件、Mobile切り替え時165件の表示。全件を精査したものではない。
- 前回閲覧した7件のうち、以下6件の採用専用サイトを参考対象とする。実サイトのPCヒーロー、本文の流れ、ナビゲーション・募集への導線を確認した。
- モバイル構成の比較は81webに掲載された静止画を使用。MOSのPC／Mobileで人物写真の見せ方が異なることを確認。実サイト6件すべてのモバイル動作検証を行ったものではない。
- ユーザーの「採用サイトを参考に」という指定に合わせ、企業トップへリンクしていたアペックは参考対象から外す。81webの分類だけで判断せず、実際に開いたページが応募者向けの採用サイトであることを確認する。
- 以下の「観察」は表示内容、「学び」「提案」は今回の設計判断。採用率や応募数の改善効果は調査していない。

| --- | --- | --- |
| [LIXIL Advanced Showroom](https://www.las-recruit.jp/) | 職員の表情と職場を大きく見せる写真、本人の関心と仕事をつなぐ紹介 | ヒーローは働く職員を主役にし、職場での自然なやりとりを見せる |

東横INN、檸檬会、日本空調サービスは、採用コンセプトとページ全体をつなぐ方法の参考とする。写真主体のヒーローについては上記3サイトを優先する。

設計の中心は、求職者が「どんな人と働くか」「どんな仕事か」「自分に合う働き方か」を判断できること。ヒーローで働く人と職場に興味を持ってもらい、仕事・職員紹介、働く環境・条件、募集・見学相談へつなぐ。1ページ化する際は各社の多ページ構成をそのまま再現せず、この判断の流れを整理する。

## 事例ごとの構成

### 1. MOS株式会社

[81web掲載](https://81-web.com/sites/43861/) ／ [実サイト](https://recruit.mosc.co.jp/)

**観察：** PCは画面を大きく使う複数の人物写真に、赤い円形のグラフィックと大きな白文字を組み合わせる。仕事着だけでなく、小物を持った表情のある人物写真が目に入る。81webのMobile画像では1人を大きく見せる。ヒーローの「芯」という言葉を、その下でロール紙の事業と社員のキャリアにつなげている。

主な流れ：ヒーロー → コンセプト・会社紹介 → 社員インタビュー → 働く環境・データ → FAQ → 募集要項・エントリー。

**学び：** 複数写真は人数・場面の説明だけでなく、人の個性を伝えるために使える。端末ごとに写真の枚数・切り抜きを変え、表情の大きさを優先する考え方を参考にしたい。

### 2. LIXIL Advanced Showroom

[81web掲載](https://81-web.com/sites/42196/) ／ [実サイト](https://www.las-recruit.jp/)

**観察：** 余白のある導入から横幅の広い人物写真へ入り、写真上にメッセージが現れる。職員の「好き」を本人の紹介へ結びつける導線がある。オレンジのアクセントと控えめな周辺装飾が共存する。

主な流れ：写真・コンセプト → 最新情報 → 会社紹介 → メッセージ・職種 → 環境・育成・FAQ → インタビュー → お知らせ・イベント → 採用区分別の入口。

**学び：** 人を支える仕事でも、働く本人の関心や専門性を主役にできる。写真の中の人物と場所を大きく見せる点が参考になる。長い導入の尺は、そのまま1ページの採用サイトには持ち込まない。

### 3. kubell

[81web掲載](https://81-web.com/sites/43169/) ／ [実サイト](https://career.kubell.com/)

**観察：** 全面に広がる職場・人物写真に、大きなコピーを重ねる。複数回の観察で写真の切り替えを確認し、ページ上にも6枚構成のスライド表示がある。ヘッダーに募集職種への導線を置き、詳しい説明は写真の後に続く。

主な流れ：ヒーロー → 挑戦・目指すものの説明 → 会社・事業 → 働く人 → 働く環境 → イベント・メディア → 採用区分 → 募集職種。

**学び：** 最初の画面で写真の面積を確保し、働く場所に入ったような距離感をつくっている。1枚ずつを大きく見せる方法と、3枚を同時に並べる方法は別の設計選択。動きの採用は、その後に判断する。

### 4. 東横INN 新卒採用

[81web掲載](https://81-web.com/sites/43732/) ／ [実サイト](https://toyoko-inn-recruit.com/newgrad/)

**観察：** 最初の画面では大きな文字、旗、応援道具などのモチーフが主役。青を中心にオレンジを加え、出発を応援するメッセージを表現している。導入文からおもてなしの考え方へつながる。

主な流れ：ヒーロー → メッセージ → おもてなし → 企業文化 → 職種 → インタビュー → 働く環境 → お知らせ。ヘッダーから募集要項・応募へ進める。

**学び：** 写真が多いこと自体が採用サイトの条件ではない。言葉、形、色が同じテーマを表しているため、入口の印象と本文がつながる。今回も先に伝えるテーマを決めたい。

### 5. 社会福祉法人 檸檬会

[81web採用一覧で掲載を確認](https://81-web.com/type/recruitment-site/) ／ [実サイト](https://recruit.lemonkai.or.jp/)

**観察：** 多色の不規則な図形、手描きの線、図形を交えたコピーを大きく使う。最初の画面は写真中心ではなく、個性や多様性という法人の考え方を示す構成。本文にはビジョン、事業、人、働く環境を置いている。

主な流れ：ヒーロー → トピックス・最新情報 → メッセージ・ビジョン → 事業 → 働く人 → データ・福利厚生 → マガジン → 問い合わせ。

**学び：** 福祉だから薄緑・明朝・穏やかな人物写真、という組み合わせに限定する必要はない。業種の一般的なイメージより、その組織が大切にするものを視覚化している。

### 6. 日本空調サービス

[81web掲載](https://81-web.com/sites/43416/) ／ [実サイト](https://www.careers.nikku.co.jp/)

**観察：** PCの最初の画面は空の広い余白に、風を思わせる手書き風の短い言葉を置く。ヘッダーの募集要項とEntryは分かれた入口。本文ではブランドメッセージ、仕事、チームの座談会、個人の紹介へ展開する。

主な流れ：ヒーロー → ブランドメッセージ → 事業・職種 → 座談会 → インタビュー → 採用情報 → 会社情報 → エントリー。

**学び：** 仕事の価値を、サイトを通して使える短い表現にまとめている。ヒーローは全情報の要約である必要はなく、その後を読みたくなる入口にもできる。

## 横断して参考にしたいこと

| 判断すること | 観察から得た設計上の示唆 |
| --- | --- |
| 最初に残す印象 | 人物、仕事の場面、言葉、図形など、視線の中心を明確にする |
| コピーと会社らしさ | 一般的な良い言葉で終わらせず、直後の事業・職員・仕事の説明につなげる |
| 写真の使い方 | 写真は説明用の小さな添え物にも、画面全体の主役にもなる。目的で面積を決める |
| ページの順序 | 感情的な入口のあとに、仕事・人・制度など判断材料を置く。順序は各社で異なる |
| 募集への導線 | 世界観を見せる部分と並行して、募集条件・応募へ進める入口を確保する |
| モバイル | PCの枚数や格子を維持するより、小さい画面でも人物・コピーが読める構成を選ぶ |
| 動き | 写真切り替え、動画、文字・図形の演出は別の役割。静止した状態の主役を決めてから動きを考える |

これは参考対象とした採用専用サイト6件からの設計上の解釈であり、81web掲載サイト全体の統計や、採用成果との因果関係を示すものではありません。

## 初稿が弱く見える理由の仮説

1. 写真3枚という条件を格子状の配置に置き換えており、最初の印象の設計が不足している。左に長いコピー、右に写真と説明が積み上がり、双方が別のまとまりに見える。
2. 3枚とも穏やかな表情・似た服・淡い室内・似た撮影距離で、場面を変えても見え方の差が小さい。色温度をそろえることと、画面の要素をすべて似せることを分けたい。
3. 利用者と職員の会話が主役のため、介護サービスの安心感は表現できても、「この人たちと働いてみたい」という採用の視点が弱い。
4. 大きな明朝、薄い緑、角丸だけでは、沖縄介護センターを記憶する手がかりが不足する。実際の職員、事務所、仕事の道具や土地の日常が必要。
5. スマホはコピーとボタンの後に写真をまとめて置くため、最初に職場の雰囲気が伝わりにくい。

いずれもデザイン上の仮説で、ユーザーが違和感を持った理由の断定ではありません。

## ヒーローの議論に出したい3案

| 案 | 最初に伝えること | 写真・コピーの構成 | 今回の位置づけ |
| --- | --- | --- | --- |
| A 働く仲間が見える | この人たちと働いてみたい | 会話や準備中の職員を大きな横写真で見せ、短いコピーを組み合わせる。2枚の補助写真は直後の導入へ。スマホは人物がすぐ目に入る順序に組み直す | 最初に比較したい案。職場の雰囲気を伝えるという依頼に合う |
| B 仕事の現場が見える | この仕事をしてみたい | 利用者との関わりを、場所も分かる写真・短い映像で大きく見せる。会話、手元、移動など動きと距離に変化をつける | 仕事の内容や意義を最優先する場合 |
| C 人の個性が並ぶ | 自分らしく働けそう | 大小・縦横の異なる人物写真を非対称に配置し、見出しとひと続きの画面にする。スマホは代表写真を主役に選び直す | 明るさや親しみやすさを強める場合。統一した撮影と編集が必要 |

調査時点の推奨はA。撮影3枚という素材数は維持できるが、3枚全部をヒーロー内の右側に収める制約は外したい。色は現在の深緑も候補として残せるが、書体・角丸・余白は新しい写真構成と一緒に評価する。議論後の決定は冒頭に記載。

### A案で撮影内容を見直すなら

- 主写真：2〜3人の職員が事務所などで自然に会話・準備をしている場面。表情に加え、実際の職場の空間が分かる少し引いた構図。
- 補助写真1：支援中の表情や手元など、仕事への向き合い方が分かる寄った構図。
- 補助写真2：訪問に出かける前後など、仕事と地域の暮らしがつながる場面。室内写真と異なる光・奥行きを持たせる。

写真の色味は整えるが、出演者・制服・事務所をダミーに合わせてそろえない。コピーは職員への短い取材で、実際の言葉と職場の特徴を確認してから詰める。

## 調査時点の扱い

参考調査の時点では方針整理のみを行った。その後、上記「議論後の決定」に従って1枚ヒーローへ復元済み。本文への写真追加は実写素材に合わせて配置を詰める。
