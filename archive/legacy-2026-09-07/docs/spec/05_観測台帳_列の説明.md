# 観測台帳 —— 列の説明

採用SNS簡易調査 納品物（付録）
沖縄介護センター様 ／ 2026年8月

`05_観測台帳.csv` は、調査で記録した採用SNS投稿の一覧です。1行＝1つの投稿。納品物1「調査結果」に出てくる数字（192.5倍・リアクション65など）の根拠はすべてこの台帳にあります。

- 期間: 2026年8月4日〜8月12日（123件）
- ファイル形式: CSV（Excel・Googleスプレッドシートで開けます）
- 記録していないもの: 第三者コメントの原文、利用者・ご家族・未成年が主体の投稿、個人が特定できる情報

## 列の説明

### 基本情報

| 列 | 意味 |
|---|---|
| 観測ID | 記録の通し番号（日付＋連番）。他の資料から根拠をたどるときに使う |
| 収集日 | 記録した日 |
| 媒体 | Instagram／TikTok／Threads／Facebook／X |
| 業界 | 介護／介護(海外)／障がい福祉／看護／保育／建設／動物病院／IT・電気設備／他業界。海外の投稿は「介護(海外)」と書き、都道府県は空欄 |
| 都道府県 | 法人の所在地（分かる場合） |
| 法人名・アカウント名 | 投稿した法人とSNSアカウント |
| アカウント種別 | 施設公式／法人採用（採用専用アカウント）／個人介護士／個人従事者／メディア |
| 投稿URL・投稿日 | 元の投稿。リンクから実物を確認できる |
| 形式 | リール（短尺動画）／動画／静止画／カルーセル（複数画像）／テキスト |

### 投稿の内容

| 列 | 意味 |
|---|---|
| 投稿の内容（ネタ名） | 何の投稿かを一言で |
| 冒頭の一文（フック） | 投稿の最初に出る言葉。見る人の足を止める役 |
| フックの種類 | 問いかけ／実演／対比 など、フックの作り方の分類 |
| 感情の引き金 | 笑い／共感／驚き など、反応を生んでいる感情 |
| 出演者 | スタッフ本人／代表者／なし など |

### 反応の数字

| 列 | 意味 |
|---|---|
| フォロワー数 | 記録時点のフォロワー数 |
| いいね数・コメント数・シェア数 | 記録時点の数。画面で確認できなかったものは空欄 |
| 反応数（合計） | 画面で見えた反応の合計 |
| 反応数÷フォロワー数 | フォロワー規模に対してどれだけ反応があったか。0.036なら3.6% |
| 普段の投稿の反応数（中央値） | 同じアカウントの普段の投稿の反応数 |
| **普段の何倍か** | その投稿が普段の何倍伸びたか。**本調査で最も重視する指標**。フォロワー数の違う他社と絶対数で比べないための数字。空欄は比較に必要な普段の投稿が揃わなかった場合 |

### 採用との関係

| 列 | 意味 |
|---|---|
| 採用の文脈 | 採用・求人に関係する投稿か（あり／なし） |
| 応募への導線 | プロフィールリンク／LINE／キャプション／コメント欄／なし |
| コメント欄の傾向 | 一般感想／同業共感／求人問い合わせ／批判 |
| リンク先の種類 | 採用ページ／法人サイト／公式LINE／外部求人サイト など。画面で見えたとおりに書いているため、表記は統一していない |
| 給与の明示・職員写真・LINE応募 | それぞれ投稿や導線にあるか（あり／なし。職員写真は「あり（イラストに変換）」も） |

### 貴社への当てはめ

| 列 | 意味 |
|---|---|
| 貴社での再現しやすさ | 高／中／低。制作の手間・必要な人材・ブランドとの相性で判断。判断していない行は空欄 |
| 貴社への応用メモ | その投稿の作り方を貴社で使うならどう変えるか。深く分析した投稿のみ記入 |

---

## 読み方のコツ

- 「普段の何倍か」が大きい行から見ると、効いている作り方が分かります
- 「貴社への応用メモ」が入っている31行が、とくに参考になる投稿です
- 空欄は「0」ではなく「確認できなかった」です。見えた数字だけを記録しています
- 「給与の明示」「職員写真」「LINE応募」「コメント欄の傾向」は、深く分析した行を中心に埋まっています。半分以上が空欄なので、この4列は件数の集計には向きません
